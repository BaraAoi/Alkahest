# Alkahest — ранняя игровая версия

## Скачать мод

[**Скачать Alkahest Alpha 0.1.0 для Minecraft 1.21.1 (JAR)**](https://github.com/BaraAoi/Alkahest/raw/refs/heads/arena/89ddcff0-alkahest/downloads/Alkahest-alpha-0.1.0-fabric-1.21.1.jar)

Это ранняя неполная версия мода. Поместите JAR в папку `mods`; также необходимы Fabric Loader, Fabric API и Trinkets для Minecraft 1.21.1. Сборка проверена автоматическими тестами, но запуск в игре пока не проверялся.

Мод разрабатывается для **Minecraft 1.21.1 / Fabric / Java 21**. Спецификация и планы находятся в `ALKAHEST_SPECIFICATION.md`. Это **не полная реализация**: исследовательская книга, Алкагест, жидкая перегонка, банки и трубы в мире, артефакты, мобы, мультиблоки, биом и Астрал пока отсутствуют. Боевые эффекты реагентов пока не реализованы. Визуальные ресурсы временные.

## Как начать

Вкладка Alkahest в творческом инвентаре содержит все готовые предметы и блоки.

1. На верстаке изготовьте алхимический котёл: ряд `медь / пусто / медь`, ряд `медь / обычный котёл / медь`, ряд из трёх камней. Поставьте под него костёр, огонь, лаву или магму и наполните его ведром воды.
2. ПКМ с предметом добавляет один ингредиент (до шести). ПКМ пустой рукой готовит, Shift + ПКМ пустой рукой возвращает ингредиенты. Котёл с водой без ингредиентов на огне за 20 секунд выпаривает 2 соли.
3. Рецепты котла: уголь или древесный уголь + пузырёк = очищенная вода; 2 цветка + еда = 2 травяные пасты; огненный порошок + редстоун = 2 огненные пыли; паучий глаз + кактус = 2 едкие слизи; соль + кристалл Ordo + нить = 2 связывающие соли; стеклянная панель + золото + кристалл Ordo = монокль. Для каждой операции нужна вода и тепло.
4. Изготовьте перегонный куб: верхние 2 ряда `медь / стекло / медь`, нижний `медь / печь / медь`. ПКМ органическим предметом добавляет один предмет; через минуту ПКМ пустой рукой забирает кристаллы или пепел. Например, яблоко может дать Herba, Aqua или Ordo. Куб пока без интерфейса и режима Алкагеста.
5. Наденьте монокль через слот Trinkets на лице: в подсказках предметов появятся их эссенции.

Содержание котла и куба сохраняется при перезагрузке мира и выпадает при разрушении блока. Обратите внимание: предусмотренная спецификацией прогрессия исследований пока отсутствует, потому эти рецепты доступны сразу.

## Сборка и запуск

Нужен JDK 21; команда `./gradlew build` создаёт JAR в `build/libs/`. Для игры установите Fabric Loader, Fabric API и Trinkets для версии 1.21.1. Тесты: `./gradlew test`. Сборка автоматически проверяется GitHub Actions, реальный запуск клиента и сервера пока не проверен.
