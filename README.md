# Alkahest — ранняя игровая версия

## Скачать мод

[**Скачать Alkahest Alpha 0.1.27 для Minecraft 1.21.1 (JAR)**](https://github.com/BaraAoi/Alkahest/raw/refs/heads/arena/89ddcff0-alkahest/downloads/Alkahest-alpha-0.1.27-fabric-1.21.1.jar)

Это ранняя неполная версия мода. Поместите JAR в папку `mods`; также необходимы Fabric Loader, Fabric API и Trinkets для Minecraft 1.21.1. Сборка и автоматический запуск клиента и сервера проверены; игровой процесс пока не проверен полностью.

Мод разрабатывается для **Minecraft 1.21.1 / Fabric / Java 21**. Полные требования — в `ALKAHEST_SPECIFICATION.md`, список работ со статусами — в [ROADMAP.md](ROADMAP.md), а памятка для продолжения разработки — в [CONTINUATION.md](CONTINUATION.md). Это **не полная реализация**: Алкагест, жидкая перегонка, банки Пустоты и Бесконечности, полноценные трубы с механизмами, артефакты экипировки, Гомункулы, Растворённый, Астральная Тень, мультиблоки, биом Пустошей и Астрал пока отсутствуют. Алхимический журнал содержит справочник и панорамную карту первых восьми узлов исследований (Эра I + начало Эры II); остальные узлы ещё не готовы. Обычные банки хранят эссенции одного типа, ранний зарядник расходует их на кристальные жезлы; остальные типы банок и большинство потребителей эссенций пока не реализованы. Элементали шести стихий и заряженная связывающая соль реализованы в 0.1.27; поздние эликсиры пока отсутствуют. Визуальные ресурсы временные.

## Как начать

Вкладка Alkahest в творческом инвентаре содержит все готовые предметы и блоки. Первое руководство можно изготовить из книги, пера, золотого самородка и любого цветка: ПКМ откроет Алхимический журнал.

1. На верстаке изготовьте алхимический котёл: ряд `медь / пусто / медь`, ряд `медь / обычный котёл / медь`, ряд из трёх камней. Поставьте под него костёр, огонь, лаву или магму и наполните его ведром воды.
2. **Разложение броском и катализатор только на ПКМ (0.1.26):** в котле нет рудиментарных слотов хранения предметов.
   - **Бросок предмета сверху (`Q`)** в нагретый котёл с водой **всегда только раскладывает предмет на эссенции** (даже если этот предмет является катализатором рецепта и в котле уже полно нужных эссенций).
   - **ПКМ предметом по котлу** проверяет **катализатор** рецепта или активной гипотезы (и сразу выдаёт результат, если нужные эссенции уже в воде); а если рецепт не готов, предмет с эссенциями растворяется в воде (**Shift + ПКМ** не-блочным предметом растворяет всю стопку). Растворённые эссенции окрашивают воду и дают цветные искры над котлом.
   - предметы без эссенций при нехватке эссенций для рецепта не застревают в котле, а подсказывают недостающие эссенции. ПКМ пустой рукой показывает растворённые эссенции в чате; **водный кристальный жезл** (`Aqua`) наполняет или очищает воду в котле за 1 заряд. Чистая вода на огне без растворённых эссенций за 20 секунд выпаривает 2 соли. Предметы из старых сохранений `<= 0.1.24`, лежавшие внутри котла, безопасно выбрасываются наружу при загрузке.
3. **Рецепты котла из эссенций** (нужны вода, тепло, растворённые эссенции и применение катализатора **ПКМ по котлу**; варка расходует воду, а лишние эссенции остаются в котле):
   - Пузырёк + `1 Aqua + 2 Ignis` = очищенная вода;
   - Семена пшеницы + `4 Herba + 2 Aqua` = 2 травяные пасты;
   - Порох + `3 Ignis + 3 Potentia` = 2 огненные пыли;
   - Сгусток слизи + `3 Vitium + 3 Herba` = 2 едкие слизи;
   - Нить + `3 Ordo + 1 Aqua` = 2 связывающие соли;
   - Стеклянная панель + `3 Ordo + 2 Lux` = монокль алхимика;
   - Громоотвод + `4 Ignis + 4 Aer + 2 Potentia` = молния в бутылке (временный рецепт до Матрицы);
   - Маринованный паучий глаз + `4 Mortuus + 3 Vitium + 2 Aqua` = миазмы (временный рецепт до Матрицы).
   **Кристаллизация излишков:** на верстаке соедините соль и кремень, чтобы получить **кристаллизующую пыль**. Бросьте её в нагретый котёл с водой или нажмите ею ПКМ по котлу — все оставшиеся эссенции превратятся в отдельные кристаллы со стабильностью **5%** (1:1). При разрушении котла оставшиеся эссенции также выпадают такими кристаллами.
4. Изготовьте перегонный куб: верхние 2 ряда `медь / стекло / медь`, нижний `медь / печь / медь`. Сам куб теперь похож на медный алхимический аппарат с камерой, трубками и дымоходом. Во время перегонки в камере движутся искры и пузырьки, куб слабо светится и выпускает декоративные частицы пара; когда работа остановлена, анимация и свет гаснут. Это только внешний эффект, он не поджигает блоки. Обычный ПКМ открывает украшенный алхимическими символами интерфейс независимо от предмета в руке. Шкала и проценты показывают прогресс; строка состояния сообщает, ожидает ли куб сырьё, работает или ждёт освобождения выхода. Положите стопку известной органики во вход; каждые 60 секунд куб переработает один предмет. В семи выходных слотах накапливаются результаты; если они заблокированы, готовый результат сохраняется внутри до освобождения места. Воронка сверху подаёт сырьё, снизу и сбоку забирает результаты.

   Куб даёт только шесть **первичных** типов: Ignis, Aqua, Terra, Aer, Ordo и Perditio. Составные эссенции в предмете раскладываются на первичные составляющие, включая вложенные формулы. Возможный тип выбирается случайно среди уникальных первичных составляющих, не по количеству; шанс пепла 20%. Например, яблоко может дать Terra и Aqua (из Herba), либо Ordo. Кристаллы одного типа в выходном слоте складываются, усредняя стабильность с учётом количества кристаллов (0.15–0.30 для новых кристаллов). Режим Алкагеста пока отсутствует.

   Для составного кристалла соедините **по одному кристаллу двух его родительских эссенций** в сетке крафта, например Ignis + Ordo = Potentia, Terra + Aqua = Herba, Mortuus + Ordo = Spiritus. Это временный ранний рецепт: результат имеет стабильность 0.15 и не требует исследования. Составные кристаллы в кубе больше не выпадают; старые сохранённые кристаллы и банки сохраняются.
5. Из палки и первичного кристалла можно скрафтить жезл (100 зарядов; после разрядки остаётся палка). Водный жезл (`Aqua`) наполняет или очищает воду в котле за 1 заряд; жезлы также настраивают трубы, а зарядник восстанавливает их от банок. Прочие способности жезлов и зарядка поясом пока не реализованы.
6. Наденьте монокль через слот Trinkets на лице: в подсказках предметов появятся их эссенции. Наведите прицел на установленную банку, чтобы увидеть содержимое и стабильность; на котёл — чтобы увидеть растворённые эссенции; на трубу — чтобы увидеть направление и фильтр. У ранних труб нет собственного запаса.
7. В инвентаре возьмите огненную пыль курсором и нажмите ПКМ по слизи (или наоборот): получится напалм. Едкая слизь + порох дают кислотную бомбу. Нужен обычный слот инвентаря игрока; если места для результата нет, он выпадет на землю.
8. Огненную пыль, едкую слизь, напалм и кислотную бомбу можно бросать ПКМ. Пыль поджигает, слизь создаёт замедляющую зону, напалм создаёт настоящий огонь в радиусе 3,5 блока на 10 секунд и восстанавливает его примерно каждые 0,25 секунды. Эффект «В напалме» поддерживает горение ещё до 8 секунд после выхода из зоны, затем обычное горение может продолжиться около 3 секунд. Кислотная бомба разово наносит 6 ед. магического урона и снимает 35 прочности с каждого предмета надетой брони. Они задевают всех рядом, в том числе бросившего игрока.

   **Новые реагенты:** Молния в бутылке создаёт настоящую ванильную молнию в точке попадания — она может наносить урон, вызывать пожар и взаимодействовать с миром. Миазмы создают облако радиусом 4 блока на 12 секунд: Wither II, Poison I и 5 прочности каждому надетому элементу брони каждую секунду. Эффекты могут ненадолго остаться после выхода. Оба реагента опасны и для бросившего игрока. Рецепты котла временные: Матрица и её расходы эссенций ещё не реализованы.
9. В новых чанках Верхнего мира на высотах 45–75 встречается соляная руда. При добыче киркой она даёт 2–4 соли, работает Удача и Шёлковое касание.

**Важно об огне:** напалм размещает обычный огонь только в подходящих местах; он может распространяться и сжигать постройки, а его обычный урон добавляется к урону зоны 3 HP/с. Для повторного возгорания напалм временно вытесняет обычные блоки воды там, где возможно поставить огонь; по окончании зоны вода восстанавливается, если клетка осталась пустой или занятой огнём. Другие блоки, в том числе водонасыщенные, не заменяются. Если вода заняла место без опоры для огня, сам блок огня там не появится, но зона продолжит наносить огненный урон; огнестойкость защищает. Распространившийся за пределы зоны огонь остаётся обычным огнём и может сохраниться после её окончания.

## Банки с эссенциями

Обычная банка — первая часть системы хранения, не вся система из спецификации. Её временный рецепт на верстаке: семь стеклянных панелей буквой U (`панель / пусто / панель`, `панель / пусто / панель`, `панель / панель / панель`). Поставьте банку и нажмите по ней ПКМ кристаллом: **пока что один кристалл превращается в 1 единицу своей эссенции**, сохраняя стабильность. Это временный способ наполнения до реализации жидкой перегонки, а не рецепт из спецификации. **Shift + ПКМ стопкой кристаллов** добавляет до доступного места; лишние кристаллы остаются в руке. ПКМ пустой рукой показывает содержимое в чате; подсказка предмета тоже показывает состав.

Банка вмещает до 100 единиц **одного типа эссенции**. Кристалл или банка другого типа не будут израсходованы и не изменят содержимое. В мире и в инвентаре виден цвет и уровень с шагом в 10 единиц (даже 1 единица видна). Точные значения есть в подсказке и по ПКМ пустой рукой. При смешивании одинакового типа стабильность усредняется с учётом объёмов. ПКМ банкой по установленной банке или ПКМ банкой, взятой курсором, по другой банке в инвентаре переливает содержимое **целиком**, оставляя исходную банку пустой. Лишнее сверх 100 испаряется без возврата; раздаётся звук и появляется дым. Разбив и заново поставив банку, можно перенести её содержимое. Обычная банка не принимает Vacuum. Извлечение содержимого обратно в кристаллы и другие виды банок пока не реализованы; не наполняйте банку ценными кристаллами в ожидании возможности их вернуть.

**Старые миры:** банки, в которых уже есть несколько типов, сохраняются без потери. Их можно переносить и разделять в ручном разделителе ниже; добавлять в них новые эссенции нельзя. Система списка в данных оставлена для безопасной загрузки старых сохранений.

## Эссенц-зарядник

На верстаке соедините **3 медных слитка, блок стекла и кристалл Potentia** в любом порядке. Кристалл Potentia получается из кристаллов Ignis + Ordo в сетке крафта. Для Ignis и Ordo можно перегонять светящиеся ягоды или золотое яблоко; результат случайный.

Поставьте банку и нажмите по ней ПКМ с зарядником: компактный зарядник установится **сверху** и автоматически привяжется к банке под ним. Над банкой должно быть свободное место; нажатие на бок банки тоже ставит его сверху. Банку можно наполнять, пока зарядник установлен. При разрушении банки зарядник останется на месте и перестанет получать эссенцию; если поставить банку обратно, он привяжется к ней автоматически. Старые установки 0.1.14 с банкой над зарядником тоже работают, но при наличии банок с обеих сторон используется только нижняя. Разбейте банку, чтобы забрать её; содержимое сохранится. Каждую секунду зарядник ищет игрока в кубе радиусом 32 блока и расходует **1 единицу нужной эссенции**, восстанавливая до **10 зарядов** одному подходящему жезлу в его инвентаре. Если в старом мире осталась смесь, зарядник по-прежнему может расходовать нужный тип из неё. Цветной след частиц показывает передачу. Разряженный до нуля жезл уже превращается в палку и не восстанавливается зарядником — заряжайте заранее.

Зарядник теперь можно добыть киркой в выживании: цельтесь в верхнюю часть крышки, находящуюся **над** банкой. Пока он поддерживает только шесть кристальных жезлов, по одному предмету за секунду; другие артефакты, слоты Trinkets и мультиблоки ещё не подключены. Перезарядка через пояс не реализована.

## Алхимические трубы

На верстаке соедините **стекло + медный слиток + кристалл Aer** в любом порядке — получится 8 труб. Aer можно получить из сырой курятины в перегонном кубе; результат случайный. Поставьте две банки и соедините их трубами. Обычный ПКМ трубой по боку банки или трубы ставит следующий сегмент; выход новой трубы направлен от той стороны, на которую вы нажали.

ПКМ **любым кристальным жезлом** по трубе последовательно меняет выход (`север → восток → юг → запад → вверх → вниз`), Shift + ПКМ жезлом переключает фильтр. Пустая рука показывает настройки в строке действия. Настройте каждый сегмент так, чтобы его выход указывал на следующий сегмент или конечную банку; у первого сегмента **источник должен быть строго напротив выхода**. Все фильтры на пути должны пропускать эссенцию. Например, `банка → труба → труба → банка` с обоими выходами на восток.

На этом раннем этапе целая направленная цепь передаёт по одной единице каждые 10 тиков напрямую из банки в банку, сохраняя стабильность; внутри труб буфера нет. Если выход заблокирован, целевая банка полна, путь зациклен, длиннее 64 сегментов или чанк не загружен — перенос останавливается без расхода. Перенос не испаряет избыток и не добавляет другой тип в занятую банку. Из старой смеси труба может извлечь подходящий тип, но в старую смешанную банку ничего не закачивает. Механизмы как входы/выходы, пустотная труба и поведение Vacuum ещё не реализованы.

## Ручной разделитель эссенций

На верстаке соедините **3 медных слитка, стекло, кварц и кристалл Ordo** в любом порядке. Это временный ранний механизм для старых банок со смесями, не полноценный Стабилизатор из спецификации. Новые смеси больше создавать нельзя.

1. Нажмите ПКМ заполненной банкой по разделителю: банка останется внутри. На блоке появится золотистая отметка.
2. Нажмите ПКМ по разделителю **пустой банкой**. В неё переливается один вид эссенции целиком, включая его стабильность; остальные виды остаются в исходной банке. Порядок определяется содержимым смеси, поэтому повторяйте с новыми пустыми банками.
3. ПКМ пустой рукой возвращает исходную банку в любой момент — даже если она уже пуста. Если разбить разделитель, находящаяся внутри банка выпадет с содержимым.

Ручное разделение не очищает и не повышает стабильность. Автоматическая подача, сортировка по выбранному типу и полноценный многоблочный Стабилизатор с очисткой пока не реализованы.

## Элементали и Заряженная Связывающая Соль (0.1.27)

В мире парят живые сгустки шести первичных стихий — **Элементали** (`Ignis`, `Aqua`, `Terra`, `Aer`, `Ordo`, `Perditio`; 30 HP, урон 5, светящееся многослойное кристаллическое ядро с орбитальными осколками; в творческой вкладке есть 6 яиц призыва):

- **Ignis** — в Незере (иммунитет к огню);
- **Aqua** — в океанах, реках и на пляжах (дышит под водой);
- **Terra** — в горах, на холмах и в карстовых/пышных пещерах;
- **Aer** — на высокогорье (`Y >= 95` при естественном спавне);
- **Ordo** — на лугах, в цветочных лесах, вишнёвых рощах и подсолнечных равнинах;
- **Perditio** — на болотах, в мангровых топях, пустошах и тёмных глубинах.

По умолчанию Элементали **нейтральны** и атакуют только в ответ. Если убить несвязанного Элементаля (или связанного не той стихией), его чистая эссенция **мгновенно испаряется** в небо столбом цветных частиц без дропа кристаллов.

Чтобы удержать эссенцию от испарения:
1. Зарядите **Связывающую соль** (`alkahest:binding_salt`) любым первичным кристаллом — **ПКМ в инвентаре** (солью по кристаллу или кристаллом по соли) либо бесформенным рецептом **на верстаке**. Получится один из 6 видов `binding_salt_<type>`.
2. Бросьте ПКМ соль **противоположной стихии** в Элементаля перед добиванием:
   - `Ignis` ↔ `Aqua` (дроп `2–4` кристалла);
   - `Terra` ↔ `Aer` (дроп `2–4` кристалла);
   - `Ordo` ↔ `Perditio` (дроп `1–2` кристалла).
3. Бросок любой связывающей соли накладывает эффект **«Кристаллизация»** (`alkahest:crystallized`) на **15 секунд**, снижая скорость передвижения и полёта на **70%**. Если стихия соли противоположна Элементалю, вокруг него смыкается вращающаяся печать из 4 кристаллов антипода, а при гибели выпадают чистые первичные кристаллы со стабильностью **65–75%**.

## Исследования в Алхимическом журнале

Откройте журнал: вкладка «Исследования» показывает панорамную карту, которую можно перетаскивать мышью; нажмите узел для подробностей, длинные записи прокручиваются колёсиком. На вкладке «Мои записи» находится справочник (8 страниц). Для проверки любой активной гипотезы **растворите предмет-основу в нагретом котле с водой** (броском или ПКМ), а затем **нажмите ПКМ выбранным образцом по котлу** (при броске в воду предмет только растворяется и не запускает гипотезу). Ошибочные варианты расходуют эссенции основы и образец, сопровождаются дымом/шипением и зачёркиваются в журнале; вода остаётся в котле.

Доступные узлы:
- **«Основы варки»**: открывается при установке/использовании котла (основа: древесный уголь).
- **«Реактивные вещества»**: после «Основ варки» сварите очищенную воду (основа: порох).
- **«Грубая перегонка»**: после «Основ варки» сварите травяную пасту (основа: травяная паста).
- **«Истинное зрение»**: после «Грубой перегонки» и «Реактивных веществ» заберите любой кристалл из перегонного куба (основа: кристалл `Ordo`).
- **«Огненный след» (0.1.27)**: после «Истинного зрения» сразите Ифрита, надев Монокль алхимика (основа: огненный стержень).
- **«Глубинное течение» (0.1.27)**: после «Истинного зрения» добудьте призмарин/морской фонарь или сразите Стража в Монокле алхимика (основа: осколок призмарина).
- **«Укрощение стихий» (0.1.27)**: после завершения «Огненного следа» и «Глубинного течения» встретьте любого Элементаля в мире, добудьте соляную руду или растворите соль в котле (основа: каменная соль `alkahest:salt`).

В старом мире уже пройденные исследования сохраняются отдельно для каждого игрока, а все рецепты остаются доступными без принудительной блокировки крафта. Остальные узлы Эры II–IV ещё не реализованы.

## Сборка и запуск

Нужен JDK 21; команда `./gradlew build` создаёт JAR в `build/libs/`. Для игры установите Fabric Loader, Fabric API и Trinkets для версии 1.21.1. Тесты: `./gradlew test` и игровые тесты `./gradlew runGametest`. Сборка, запуск клиента и сервера, смешивание реагентов, эффект кислоты, возобновление огня, восстановление воды, действие напалма, растворение эссенций и катализаторы котла, узлы исследований Эры I и Эры II, грубая перегонка, банки, зарядник, трубы, ручной разделитель, заряженная связывающая соль, эффект `crystallized`, а также испарение и антиподное связывание Элементалей автоматически проверяются в GitHub Actions. Запуск клиента — только smoke-тест; новая версия ещё требует проверки пользователем в игре.
