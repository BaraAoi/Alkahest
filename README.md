# Alkahest — ранняя игровая версия

## Скачать мод

[**Скачать Alkahest Alpha 0.1.3 для Minecraft 1.21.1 (JAR)**](https://github.com/BaraAoi/Alkahest/raw/refs/heads/arena/89ddcff0-alkahest/downloads/Alkahest-alpha-0.1.3-fabric-1.21.1.jar)

Это ранняя неполная версия мода. Поместите JAR в папку `mods`; также необходимы Fabric Loader, Fabric API и Trinkets для Minecraft 1.21.1. Сборка и автоматический запуск клиента и сервера проверены; игровой процесс пока не проверен полностью.

Мод разрабатывается для **Minecraft 1.21.1 / Fabric / Java 21**. Спецификация и планы находятся в `ALKAHEST_SPECIFICATION.md`. Это **не полная реализация**: исследовательская книга, Алкагест, жидкая перегонка, банки и трубы в мире, артефакты, мобы, мультиблоки, биом и Астрал пока отсутствуют. Элементали, применение связывающей соли и поздние реагенты пока не реализованы. Визуальные ресурсы временные.

## Как начать

Вкладка Alkahest в творческом инвентаре содержит все готовые предметы и блоки.

1. На верстаке изготовьте алхимический котёл: ряд `медь / пусто / медь`, ряд `медь / обычный котёл / медь`, ряд из трёх камней. Поставьте под него костёр, огонь, лаву или магму и наполните его ведром воды.
2. ПКМ с предметом добавляет один ингредиент (до шести). ПКМ пустой рукой или кристальным жезлом готовит, Shift + ПКМ пустой рукой возвращает ингредиенты. Вода теперь видна внутри котла; котёл с водой без ингредиентов на огне за 20 секунд выпаривает 2 соли.
3. Рецепты котла: уголь или древесный уголь + пузырёк = очищенная вода; 2 цветка + еда = 2 травяные пасты; огненный порошок + редстоун = 2 огненные пыли; паучий глаз + кактус = 2 едкие слизи; соль + кристалл Ordo + нить = 2 связывающие соли; стеклянная панель + золото + кристалл Ordo = монокль. Для каждой операции нужна вода и тепло.
4. Изготовьте перегонный куб: верхние 2 ряда `медь / стекло / медь`, нижний `медь / печь / медь`. ПКМ органическим предметом добавляет один предмет; через минуту ПКМ пустой рукой забирает кристаллы или пепел. Например, яблоко может дать Herba, Aqua или Ordo. Куб пока без интерфейса и режима Алкагеста.
5. Из палки и первичного кристалла можно скрафтить жезл. Он активирует котёл и расходует 1 из 100 зарядов при успешной варке; после разрядки остаётся палка. Прочие способности и зарядка жезлов пока не реализованы.
6. Наденьте монокль через слот Trinkets на лице: в подсказках предметов появятся их эссенции.
7. В инвентаре возьмите огненную пыль курсором и нажмите ПКМ по слизи (или наоборот): получится напалм. Едкая слизь + порох дают кислотную бомбу. Нужен обычный слот инвентаря игрока; если места для результата нет, он выпадет на землю.
8. Огненную пыль, едкую слизь, напалм и кислотную бомбу можно бросать ПКМ. Пыль поджигает, слизь создаёт замедляющую зону, напалм наносит урон в огненной зоне, кислотная бомба наносит урон и портит броню. Они задевают всех рядом, в том числе бросившего игрока.
9. В новых чанках Верхнего мира на высотах 45–75 встречается соляная руда. При добыче киркой она даёт 2–4 соли, работает Удача и Шёлковое касание.

Вода в старых сохранённых котлах появится после загрузки чанка. Содержание котла и куба сохраняется при перезагрузке мира и выпадает при разрушении блока. Обратите внимание: предусмотренная спецификацией прогрессия исследований пока отсутствует, потому эти рецепты доступны сразу.

## Сборка и запуск

Нужен JDK 21; команда `./gradlew build` создаёт JAR в `build/libs/`. Для игры установите Fabric Loader, Fabric API и Trinkets для версии 1.21.1. Тесты: `./gradlew test` и игровые тесты `./gradlew runGametest`. Сборка, запуск клиента и сервера, смешивание реагентов и их основные эффекты автоматически проверяются в GitHub Actions.
