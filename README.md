# Alkahest

Ранняя основа мода для Minecraft **1.21.1**, Fabric и Java 21. Полное техническое задание находится в `ALKAHEST_SPECIFICATION.md`.

## Текущая реализация

- 17 типов эссенций, их цвета, состав и противоположности; модель стабильности и содержимого банки.
- Data Components для содержимого банки, заряда, душ, привязки к душе, фильтра и стабильности. Данные предметов не используют старый ItemStack NBT API.
- Базовая карта эссенций для ванильных предметов и тегов, монокль Trinkets, показывающий эти значения в подсказке, и 16 предметов-кристаллов во вкладке креатива.
- Чистая функция смешивания содержимого банок со средневзвешенной стабильностью и испарением избытка (правила Vacuum и игровое взаимодействие ещё не подключены).

**Это не готовый игровой мод по всей спецификации.** Котёл, рецепты, журнал, механизмы, взаимодействие с банками, мобы, мультиблоки, измерение, генерация мира и большинство предметов пока не реализованы. Монокль и кристаллы пока доступны только через творческий инвентарь или команды. Текстуры являются простыми временными пиксельными изображениями.

## Сборка

Установите JDK 21, затем запустите `./gradlew build` (Windows: `gradlew.bat build`). Gradle скачает Fabric Loom, Minecraft, Fabric API и Trinkets; сборке нужен доступ к их Maven-репозиториям. Готовый файл будет в `build/libs/` (не `-sources.jar`). Для игры также нужны Fabric Loader, Fabric API и Trinkets для 1.21.1. Для тестов: `./gradlew test`.

Сборка и запуск клиента в текущем окружении не проверены: JDK отсутствует, а серверы Gradle, Minecraft и Fabric Maven недоступны. До выпуска jar необходимо выполнить сборку и проверить мод в клиенте и на выделенном сервере.
